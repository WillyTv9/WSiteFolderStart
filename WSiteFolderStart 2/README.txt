WSiteFolderStart

macOS:   cd macOS && ./build.sh   ->  WSiteFolderStart.app (trascinala in Applicazioni)
Windows: cd Windows && dotnet publish -c Release -r win-x64 --self-contained false
         -> bin\Release\net8.0-windows\win-x64\publish\WSiteFolderStart.exe

La cartella viene creata sul Desktop.
